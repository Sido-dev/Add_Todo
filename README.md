# 📝 Personal Task Manager (Todo App)

A simple and interactive **Todo List Web App** that allows users to add tasks with a due date and remove them when completed. The app uses **localStorage** to save tasks, so your data persists even after refreshing the page.

---

## 🚀 Features
- ➕ Add tasks with a due date  
- ❌ Delete tasks instantly  
- 💾 Persistent storage using localStorage  
- 🎨 Clean UI with gradient background  
- 📱 Responsive layout  

---

## 🛠️ Tech Stack
- HTML – Structure
- CSS – Styling & Layout
- JavaScript – Functionality & Logic

---

## ⚙️ How It Works
- Enter a task and select a due date  
- Click **ADD** to store the task  
- Tasks are displayed dynamically  
- Each task has a **Delete** button  
- Data is saved in localStorage
